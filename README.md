### Running the code with python framework
```bash
python3 --version

pip3 install
fastapi pip3 
install uvicorn
```

```new bash (Mac OS)
python3 --version
pip3 install pandas fastapi pydantic uvicorn
uvicorn main:app --reload
```

uvicorn main:app --reload http://127.0.0.1:8000/docs
